# Edit Mode — сценарії перевірки

Епік 008 ([запис](../implementation/008-edit-mode.md)). Сторінка для тестів — лендинг «Luminary»
(`/admin/edit/`), друга сторінка — `/admin/edit/about`. Середовище й акаунти — у [README](./README.md).

Якщо не сказано інше: вхід як `owner@example.com`, сторінка `/admin/edit/`.

---

## Відкриття і рендер

### EM-OPEN-01 — Сторінка сайту в редакторі
**Кроки:** відкрити `/admin/edit/`.
**Очікувано:** та сама сторінка, що й `/`, з header і footer. Тулбар зверху. Нередаговане затемнене,
поля — у пунктирних контурах. Помилок у консолі немає.
**E2E:** так.

### EM-OPEN-03 — Без права редагування
**Передумови:** вхід як `customer@example.com` (без доступу до CMS).
**Кроки:** відкрити `/admin/edit/`.
**Очікувано:** редирект, редактор не відкривається.
**E2E:** так.

### EM-OPEN-04 — Публічний сайт без коду редактора
**Кроки:** `npm run build`, запустити `.output`, відкрити `/`, у DevTools → Network подивитися JS / CSS.
**Очікувано:** немає чанків Tiptap / ProseMirror / overlay / admin CSS. `npm run check:bundle` — OK.
**E2E:** так (`check:bundle` вже автоматичний; Network — ручна частина).

## Текст і rich text

### EM-TEXT-01 — Регістр тексту з CSS uppercase
**Кроки:** клікнути «CREATIVE STUDIO» (eyebrow у hero), дописати `x`, Enter, Save draft. Відкрити
SQL: `select content->'hero'->'eyebrow' from cms_page_draft;`.
**Очікувано:** збережено `Creative studiox`, а не `CREATIVE STUDIOX`.
**E2E:** так.

### EM-TEXT-02 — Лічильник і ліміт
**Кроки:** у заголовку hero (ліміт 75) дописувати текст до 70, потім до 80 символів.
**Очікувано:** від ~68 лічильник жовтий, після 75 — червоний. У тулбарі «Проблем, що блокують
публікацію: 1». Publish замість публікації переводить до поля.
**E2E:** так.

### EM-TEXT-03 — Обов'язкове поле
**Кроки:** очистити заголовок hero повністю, клікнути поза ним.
**Очікувано:** плейсхолдер у порожньому полі, «Обов'язкове» в міні-панелі, проблема в списку тулбара.
Клік по проблемі веде до поля.
**E2E:** так.

### EM-TEXT-04 — Rich text: форматування і лінк
**Кроки:** у тексті блоку About виділити слово → B, I, Link → `javascript:alert(1)`.
**Очікувано:** bold / italic працюють. Для `javascript:` — помилка «Недозволена адреса», «Готово» не
ставить лінк. З `/about` лінк ставиться, клік по ньому в редакторі не переходить.
**E2E:** так.

### EM-TEXT-05 — Reset поля
**Кроки:** змінити текст, у міні-панелі «Скинути» → підтвердити.
**Очікувано:** текст опублікованої версії (або дефолт коду). Фокус на «Скасувати» в діалозі.
**E2E:** так.

## Save, Publish, Undo

### EM-SAVE-01 — Збереження і публікація
**Кроки:** змінити текст → Cmd+S → Publish → відкрити `/` в іншій вкладці.
**Очікувано:** статус «Чернетка не опублікована», потім «Опубліковано». На `/` новий текст.
**E2E:** так.

### EM-SAVE-02 — Cmd+S не викидає з тексту
**Кроки:** друкувати в полі, Cmd+S, продовжити друкувати, Cmd+Z.
**Очікувано:** після Cmd+S курсор лишається в полі. Undo скасовує лише текст після збереження.
**E2E:** так.

### EM-SAVE-05 — Undo після Publish
**Кроки:** змінити текст → Publish → Cmd+Z.
**Очікувано:** Undo вимкнено, опубліковане не відкочується (C-64).
**E2E:** так.

### EM-SAVE-07 — History і Restore
**Передумови:** щонайменше дві публікації.
**Кроки:** History → «Відновити» старшу версію → підтвердити.
**Очікувано:** версія стає чернеткою, сайт не змінюється до Publish. Esc закриває drawer, фокус
повертається на кнопку History.
**E2E:** так.

## Лінки, кнопки, навігація

### EM-NAV-01 — Клік по кнопці вибирає, не переходить
**Кроки:** клікнути «Start a project».
**Очікувано:** popover з підписом і адресою, переходу немає.
**E2E:** так.

### EM-NAV-02 — Cmd+клік і «Відкрити»
**Кроки:** Cmd+клік по «See our work»; окремо — в popover «Відкрити ↗» для `/#contact`.
**Очікувано:** перехід / прокрутка до секції, лишаємось в Edit Mode.
**E2E:** так.

### EM-NAV-03 — Лінк header з незбереженими змінами
**Кроки:** змінити текст, клікнути «About» у header.
**Очікувано:** діалог «Вийти без збереження?»: «Зберегти й вийти» / «Вийти без збереження» /
«Скасувати». Після виходу — `/admin/edit/about`.
**E2E:** так.

### EM-NAV-04 — Кнопка «Назад» браузера з незбереженими змінами
**Кроки:** змінити текст, Back.
**Очікувано:** той самий діалог.
**E2E:** так.

### EM-NAV-05 — Закриття вкладки з незбереженими змінами
**Кроки:** змінити текст, закрити вкладку.
**Очікувано:** системне попередження браузера.
**E2E:** ні — нативний діалог `beforeunload`.

## Колекції і optional

### EM-COLL-01 — Додати, дублювати, видалити
**Кроки:** навести на картку Services → «+» (додати після) → дублювати → видалити → «Undo» у toast.
**Очікувано:** нова картка вибрана й у фокусі. Після видалення фокус на сусідній картці. Undo
повертає її.
**E2E:** так.

### EM-COLL-03 — Reorder мишею, кнопками і клавіатурою
**Кроки:** перетягнути handle; ↑ / ↓; Tab до картки → Enter → стрілки → Cmd+Z.
**Очікувано:** порядок змінюється, зчитувач чує «Переміщено на позицію 2 з 3», Cmd+Z повертає. Esc
під час перетягування скасовує його.
**E2E:** так (миша й клавіатура).

### EM-COLL-04 — Reset дефолтної картки
**Передумови:** колекція ще не збережена (дефолти з коду).
**Кроки:** змінити заголовок першої картки → Reset.
**Очікувано:** повертається дефолтний заголовок, поле не порожнє.
**E2E:** так.

### EM-OPT-01 — Сховати й показати блок
**Кроки:** клік по порожньому місцю секції з відгуком → «Приховати» → Preview → вийти з Preview →
«Показати».
**Очікувано:** у редакторі плашка «Приховано: Testimonial · Показати», у Preview блоку немає.
**E2E:** так.

## Content Lock

Два браузери: A — звичайне вікно, B — інкогніто. Стан lock у базі:

```sql
select p.key, u.email, l.acquired_at, l.heartbeat_at
from cms_page_locks l
join cms_pages p on p.id = l.page_id
join auth.users u on u.id = l.user_id;
```

### EM-LOCK-01 — Інший користувач уже редагує
**Кроки:** A: owner відкриває `/admin/edit/`. B: admin відкриває ту саму сторінку.
**Очікувано:** у B банер «owner@example.com редагує цю сторінку від HH:MM», поля не редагуються,
Save / Publish вимкнені.
**E2E:** так (два browser context).

### EM-LOCK-02 — Забрати редагування
**Кроки:** продовження EM-LOCK-01. У B «Забрати редагування» → підтвердити. В A змінити текст → Cmd+S.
**Очікувано:** B редагує. В A жовтий банер «Ваша сесія редагування більше не активна», набраний текст
на місці.
**E2E:** так.

### EM-LOCK-03 — Забрати назад, коли сторінка зайнята
**Кроки:** продовження EM-LOCK-02. В A «Забрати назад і продовжити», поки B на сторінці.
**Очікувано:** повідомлення «Сторінку досі редагує інший користувач». A лишається в стані «сесія
неактивна»: вихід з незбереженими змінами далі питає підтвердження.
**E2E:** так.

### EM-LOCK-04 — Забрати назад після чужої публікації
**Кроки:** A втратив lock (EM-LOCK-02) без власних змін. B змінює заголовок → Publish → виходить.
A «Забрати назад».
**Очікувано:** A бачить заголовок від B, Undo порожній.
**E2E:** так.

### EM-LOCK-05 — Роль без force unlock
**Кроки:** як EM-LOCK-01, але B — `editor@example.com`.
**Очікувано:** банер без кнопки «Забрати редагування».
**E2E:** так.

### EM-LOCK-06 — Та сама людина у двох вкладках
**Кроки:** owner відкриває `/admin/edit/` у двох вкладках. У першій змінити текст → Cmd+S.
**Очікувано:** друга вкладка забрала lock одразу; перша показує «сесія неактивна».
**E2E:** так.

### EM-LOCK-07 — Закриття вкладки звільняє lock
**Кроки:** A редагує, B бачить банер. Закрити вкладку A, перезавантажити B.
**Очікувано:** B одразу редагує, не чекаючи 2 хв. У базі рядка lock немає.
**E2E:** так (закрити page у context).

### EM-LOCK-08 — Протермінований lock
**Кроки:** A редагує. Імітувати зупинку heartbeat:
`update cms_page_locks set heartbeat_at = now() - interval '3 minutes';`. Почекати до 30 с у B.
**Очікувано:** банер у B дописує «Схоже, ця сесія неактивна»; кнопка «Забрати редагування» є навіть у
editor і спрацьовує без підтвердження.
**E2E:** так (через SQL); ручний варіант — закрити ноутбук A на 2+ хв.

## Клавіатура і доступність

### EM-A11Y-01 — Усе з клавіатури
**Кроки:** Tab по сторінці: текст, кнопка, зображення, картка. Enter на зображенні / картці.
**Очікувано:** видимий фокус на кожному полі. Enter відкриває панель і переводить у неї фокус. Esc
повертає фокус на поле; ще раз Esc піднімає вибір рівнем вище (поле → картка → колекція).
**E2E:** так.

### EM-A11Y-02 — Діалоги і фокус
**Кроки:** Reset поля (деструктивний діалог) → Enter.
**Очікувано:** фокус на «Скасувати», Enter нічого не скидає. Після закриття фокус повертається туди,
де був.
**E2E:** так.
