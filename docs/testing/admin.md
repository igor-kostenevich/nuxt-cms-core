# Адмінка — сценарії перевірки

Оболонка, Settings → General, мова адмінки (епіки 004a–004c,
[004b](../implementation/004b-admin-shell-settings.md), [004c](../implementation/004c-alignment.md)).

### ADM-SET-01 — Збереження налаштувань
**Кроки:** вхід як owner → Settings → змінити «Назву сайту» й email → Зберегти → перезавантажити.
**Очікувано:** «Збережено», після перезавантаження нові значення. Назва в сайдбарі оновилась.
**E2E:** так.

### ADM-SET-02 — Валідація форми
**Кроки:** очистити назву сайту, ввести `not-an-email` → Зберегти.
**Очікувано:** помилки біля полів, нічого не збережено. Після виправлення помилки зникають.
**E2E:** так.

### ADM-SET-03 — Editor бачить, але не змінює
**Кроки:** вхід як `editor@example.com` → Settings.
**Очікувано:** банер «лише перегляд», поля і кнопка вимкнені. Прямий запит з консолі браузера не
змінює рядок (RLS `cms_can('settings.update')`).
**E2E:** так (UI); RLS покриває pgTAP.

### ADM-I18N-01 — Мова адмінки окремо від мови сайту
**Кроки:** у шапці адмінки перемкнути EN ↔ UK → перезавантажити → відкрити `/admin/edit/`.
**Очікувано:** мова зберігається (cookie), редактор теж у вибраній мові. Мова самого сайту не
змінюється, `lang` сторінки сайту в редакторі — мова сайту.
**E2E:** так.

### ADM-SEL-01 — Селект адмінки
**Кроки:** Media → сортування; шапка → мова. Мишею: відкрити, вибрати. Клавіатурою: Tab на селект →
↓ (відкриває) → ↓ → Enter; ↓ → Esc; закритий селект + літера (`o` → «Oldest»). У модалі медіатеки Esc
у відкритому селекті закриває лише список.
**Очікувано:** поле й список — один блок зі спільною синьою рамкою і роздільником; вибране — синім,
активне — сірим. Біля низу вікна список відкривається вгору; якщо місця немає ні знизу, ні зверху
(низьке вікно) — лишається внизу. У модалі Picker список не обрізається. Клік поза списком закриває
його. Скрінрідер читає назву поля, значення і стан «розгорнуто».
**E2E:** так.
