# Медіа — сценарії перевірки

Епік 009 ([запис](../implementation/009-media.md)): медіатека `/admin/media`, Media Picker в Edit Mode,
Settings → Brand, рендер на публічному сайті. Середовище й акаунти — у [README](./README.md).

Тестові файли: будь-які JPG / PNG / WebP / SVG до 5 МБ, плюс файл понад 5 МБ і GIF / PDF для
негативних сценаріїв.

---

## Медіатека

### MD-LIB-01 — Upload і картка
**Кроки:** вхід як editor → Media → Upload → PNG.
**Очікувано:** картка-заглушка «Завантаження…», потім картка з мініатюрою, ім'ям, розміром і «Не
використовується». У модалі файла — розміри в px.
**E2E:** так.

### MD-LIB-02 — Неприйнятний файл
**Кроки:** Upload GIF, потім PNG понад 5 МБ.
**Очікувано:** червоні картки з причиною («Виберіть зображення JPG, PNG, WebP або SVG», «Файл
більший за 5 МБ»), запиту в Storage немає (Network). «Прибрати» ховає картку.
**E2E:** так.

### MD-LIB-03 — Drag & drop кількох файлів
**Кроки:** перетягнути на сітку три файли.
**Очікувано:** рамка «Відпустіть файли…», три картки по черзі.
**E2E:** так.

### MD-LIB-04 — Пошук, тип, сортування
**Кроки:** ввести частину імені; «SVG»; «За розміром».
**Очікувано:** список фільтрується після паузи в друку; лічильник «Файлів: N» збігається з сіткою.
Пошук `50%` шукає текст, а не шаблон.
**E2E:** так.

### MD-LIB-05 — Метадані
**Кроки:** модал файла → нове ім'я, default alt, точка фокусу → Зберегти → перезавантажити.
**Очікувано:** значення збережено. Порожнє ім'я не дає зберегти.
**E2E:** так.

### MD-LIB-06 — Replace
**Передумови:** файл використовується на `/` (див. MD-EDIT-01).
**Кроки:** модал файла → «Замінити файл» → інше зображення → відкрити `/`.
**Очікувано:** на сайті новий файл без зміни контенту сторінки. URL файла новий (інший storage path),
старий об'єкт зник зі Studio → Storage → `cms-media` (R-13).
**E2E:** так.

### MD-LIB-07 — Використаний файл не видаляється
**Передумови:** файл використовується на `/` і як логотип (або лише в записі 014).
**Кроки:** вхід як admin → модал файла → Видалити.
**Очікувано:** файл не видалено: повідомлення «Цей файл використовується на сайті. Спершу приберіть його
звідти…» (`media_in_use`), картка на місці, на `/` і в логотипі — той самий файл. Після того як файл
прибрано з усіх місць (сторінки, записи, Brand), видалення проходить.
*Змінено в 014 / 2c (рішення автора, C-77):* раніше використаний файл видалявся після попередження.
До етапу 5 014 модал ще пропонує «Видалити файл» і показує це повідомлення як помилку.
**E2E:** так.

### MD-LIB-08 — Editor не видаляє
**Кроки:** вхід як editor → модал файла.
**Очікувано:** кнопки «Видалити» немає. Прямий виклик `cms_media_delete` повертає permission denied
(покриває pgTAP).
**E2E:** так (UI).

## Edit Mode

### MD-EDIT-01 — Picker → Save → Publish → сайт
**Кроки:** вхід як admin → `/admin/edit/` → фото студії → «Вибрати з медіатеки» → файл → «Вибрати»
→ Alt-текст → Publish → відкрити `/`, переглянути HTML (View Source).
**Очікувано:** у серверному HTML `<img>` з URL `…/storage/v1/object/public/cms-media/…` і введеним alt.
Картка файла в медіатеці показує «home».
**E2E:** так.

### MD-EDIT-02 — Пріоритет alt (C-74)
**Кроки:** у файла default alt «A». На сторінці: (1) без override, (2) override «B», (3) «Декоративне».
**Очікувано:** alt на сайті — «A», «B», порожній. Без default alt і без override — alt з коду сайту.
**E2E:** так.

### MD-EDIT-03 — Upload прямо з панелі
**Кроки:** панель зображення → «Завантажити з пристрою» → PNG.
**Очікувано:** файл з'являється в медіатеці й одразу стоїть у полі. Невідповідний файл — помилка в
панелі, поле не змінюється.
**E2E:** так.

### MD-EDIT-07 — Перетягування точки фокусу
**Кроки:** панель зображення → затиснути точку фокусу і тягнути (мишею; на планшеті — пальцем), зокрема
за межі картинки → відпустити → Cmd+Z.
**Очікувано:** точка йде за курсором, зображення на сторінці зсувається наживо; за межами картинки
точка впирається в край (0–100%) і видна повністю. Сторінка під пальцем не скролиться. Один Cmd+Z
повертає точку, де вона була до жесту (один жест — один крок Undo). Клік без руху ставить точку,
стрілки зсувають її. Те саме в модалі медіатеки, без Undo.
**E2E:** так.

### MD-EDIT-08 — Точка фокусу лише при обрізці
**Кроки:** вибрати файл для фото студії (показується повністю) і для обкладинки проєкту (рамка `10 / 7`)
— портретне фото. Звузити вікно, відкрити фон hero.
**Очікувано:** у фото студії замість точки — «Тут зображення показується повністю…». В обкладинці —
точка і рамка видимої частини, решта затемнена; рамка рухається лише по осі, де є обрізка (для
портретного фото — вгору-вниз), і зображення на сторінці зсувається так само. Фон hero на вузькому
вікні отримує точку, щойно починає обрізатись.
**E2E:** так.

### MD-EDIT-04 — Undo і Reset зображення
**Кроки:** вибрати інше зображення → Cmd+Z → Cmd+Shift+Z → Reset поля.
**Очікувано:** Undo повертає попереднє зображення, Redo — нове, Reset — опубліковане. Те саме для
фону hero (`CmsBackground`).
**E2E:** так.

### MD-EDIT-05 — Чернетка використовує файл
**Кроки:** вибрати файл, Save draft (без Publish) → медіатека.
**Очікувано:** бейдж «home (чернетка)». Після Publish — «home».
**E2E:** так.

### MD-EDIT-06 — Restore старої версії з видаленим файлом (обмеження V1)
**Передумови:** файл був на сторінці в опублікованій версії, потім його замінили іншим і опублікували;
файл більше ніде не використовується (ревізії використанням не вважаються, C-72) і його видалили.
**Кроки:** Edit Mode → History → Restore старої версії → Publish.
**Очікувано:** поле показує зображення з коду, панель пропонує вибрати з медіатеки. Restore і Publish
не падають. Це задокументоване обмеження V1: ревізії не захищають файли від видалення.
*Змінено в 014 / 2c:* сценарій «файл видалено, поки сторінка в чернетці» більше неможливий — файл,
який використовує чернетка, не видаляється (MD-LIB-07).
**E2E:** так.

## Settings → Brand і публічний сайт

### MD-BRAND-01 — Логотип і favicon
**Кроки:** вхід як admin → Settings → Бренд → Логотип «Вибрати» → файл; так само favicon → відкрити `/`.
**Очікувано:** у header playground — зображення-логотип, у вкладці — favicon. «Прибрати» повертає
wordmark і дефолтний favicon.
**E2E:** так.

### MD-BRAND-02 — Editor бачить Brand лише для читання
**Кроки:** вхід як editor → Settings.
**Очікувано:** секція Бренд без кнопок «Вибрати» / «Прибрати».
**E2E:** так.

### MD-PUB-01 — Public без коду медіатеки
**Кроки:** `npm run build`, запустити `.output`, відкрити `/`, DevTools → Network.
**Очікувано:** немає чанків `AdminMedia*`, `ImagePanel`, editor, admin CSS. Зображення — зі Storage.
`npm run check:bundle` — OK.
**E2E:** так.

### MD-SEC-01 — SVG очищується перед upload
**Кроки:** завантажити SVG з `<script>`, `onload`, `<a href="javascript:…">`, `<foreignObject>`,
`<animate>` / `<set>` і `<style>@import …</style>`. Відкрити URL файла з картки напряму в браузері;
поставити його на сторінку і відкрити `/`.
**Очікувано:** у Storage лежить файл без цих частин (форми й текст на місці). Жодного alert — ні за
прямим URL, ні в адмінці, ні на сайті (C-75).
**E2E:** так.

### MD-SEC-02 — Нормальний SVG не псується
**Кроки:** завантажити логотип із градієнтом (`fill="url(#g)"`), `<use href="#…">` і `<style>` з класами.
**Очікувано:** картка й сайт показують його так само, як у редакторі графіки.
**E2E:** так.

### MD-SEC-03 — Зламаний SVG
**Кроки:** завантажити текстовий файл з розширенням `.svg` (не XML).
**Очікувано:** червона картка «Не вдалося прочитати цей SVG…», у Storage нічого не з'явилось.
**E2E:** так.
